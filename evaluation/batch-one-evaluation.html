How these decks were verified

Because automated image viewing returned metadata rather than visible pixels in this environment, verification was mechanical and layered. Format integrity: pdfinfo page counts and python-pptx slide read-backs for every PDF and PPTX, archive entry counts for every zip — all fifteen packages matched their expected slide counts exactly (12, 10, 11, 11, 13). Content: full-resolution OCR sweeps per slide, with crop-and-zoom passes on disputed text. Palette: HSV signatures computed from the actual slide pixels, confirming each deck's visual direction is real and distinct. Numbers: every company-specific figure was cross-checked against the placeholder-metrics register (16 entries), and market/regulation claims against the sourced facts document.

One flagged defect — V1's title reading "The night runs on datas." in an OCR pass — was investigated at pixel level: glyph-component geometry of the headline band shows the word box is exactly filled by d-a-t-a-period, with no glyph where an "s" would be (~40×50 px at this scale). The "s" was photo texture beside the text. The delivered V1 package is correct and unchanged.
